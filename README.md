# Автоберлога — сайт автосервиса

Одностраничный сайт автосервиса «Автоберлога» (Ростов-на-Дону,
ул. Александра Блока, 27).

Чистая статика: HTML + CSS + JS, без сборки. Открывается как есть.

- `index.html` — каркас страницы
- `content.js` — все тексты
- `config.js` — контакты, график работы, ссылки
- `theme.css` — цвета и типографика
- `base.css` / `blocks.css` — вёрстка
- `app.js` — рендер и интерактив
- `img/` — логотип и карта

Карта собрана из тайлов © OpenStreetMap contributors.
